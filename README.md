# VantaTracker

A desktop Valorant companion: live match lobby (ranks, peak, win rate, last games, skins), your store and night market,
missions and inventory, stats, match history and a crosshair library. English, Türkçe and Español.

**Download:** https://github.com/mrchavoo/vantatracker-releases/releases/latest  
Run the installer; the app checks GitHub for new versions and offers to update itself.

## How it works
VantaTracker reads data from the Riot Client that is already running on your PC (the same local interface other trackers use)
and from public sources such as valorant-api.com. It never asks for your Riot password and does not send your data to any server of ours.
The Riot Client's local interface is **not officially supported by Riot Games**, so features can break after game updates. Use at your own risk.

## Hotkey
`Alt+C` (changeable in Settings) shows or hides a small overlay in the top-right corner. Valorant must run in *Windowed Fullscreen* for overlays to be visible.
