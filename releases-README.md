# VantaTracker

A desktop Valorant companion: live match lobby (ranks, peak, win rate, last games, skins), store and night market,
missions and inventory, stats, match history and a crosshair library. English, Türkçe and Español.

## Download
**[Download the latest installer](https://github.com/mrchavoo/vantatracker-releases/releases/latest)** and run `VantaTracker-Setup-x.y.z.exe`.
The app checks for new versions on its own and offers to update itself.

Windows may show a "Windows protected your PC" notice because the installer isn't code-signed: choose **More info > Run anyway**.

## Good to know
- It never asks for your Riot password and doesn't send your data to any server of ours.
- It reads from the Riot Client running on your PC through an interface that Riot Games doesn't officially support, so features can break after game updates. Use at your own risk.
- Overlay: `Alt+C` (changeable in Settings). Valorant must run in *Windowed Fullscreen* for overlays to be visible.
