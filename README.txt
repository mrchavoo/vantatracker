RUN
1. npm install
2. npm start

BUILD AN INSTALLER (.exe)
Double-click yukleyici-olustur.bat. When it finishes, the installer is in the dist folder.

OVERLAY
Press Alt+C (changeable in Settings) to show/hide a small overlay in the top-right corner.
It does not take focus from the game. You can click the overlay to browse every menu (Settings: you can make clicks pass through instead).
Valorant must be in Windowed Fullscreen mode for overlays to be visible.

LANGUAGE
The app starts in English. Change it any time in Settings (English, Turkce, Espanol).
